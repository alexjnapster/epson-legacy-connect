# Security and privacy

Do not include Wi-Fi passwords, network captures, serial numbers, local IP addresses, MAC addresses, or personal file contents in public reports. Describe the model, macOS version, connection type, and sanitized error instead.

The app validates official downloaded components before use, bounds USB messages, escapes XML field values, rejects XML external entities and malformed responses, and passes process arguments without a shell. Printer replies and Bonjour advertisements are untrusted input.

The local network printer protocols on this generation are legacy protocols. This tool does not expose the printer to the internet or configure router port forwarding. Use a trusted local network.

Epson component licences remain separate from the MIT licence for this source. The app does not automatically accept vendor licence terms or bypass administrator authorization, Gatekeeper, certificate validation, or network isolation.

Report a suspected vulnerability privately using the repository owner's GitHub profile contact options if available. Do not publish a working credential or private capture in an issue.
